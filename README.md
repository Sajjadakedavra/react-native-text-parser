# React Native EULA / Terms & Conditions Renderer

A small yet powerful React Native package that simplifies rendering long EULA, Privacy Policies, or any similar text directly inside your app. This package makes it easy to:

- Parse and render long structured texts like legal documents.
- Apply custom styles to parts of the text.
- Detect and handle special patterns such as links, phone numbers, and more.
- Provide interaction handlers for custom tap actions.

## Features

- Renders long structured documents (EULA, Privacy Policy, etc.) from a defined schema.
- Supports pattern detection (URLs, phone numbers, keywords, etc.) with custom tap handlers.
- Easily apply inline and block-level styles.
- Detects clickable content like `google.com` or `+123456789` and performs user-defined actions (open browser, call phone, etc.)
- Fully customizable styling and behavior.
